# car-sentry · 车辆哨兵

基于 **ESP32-CAM + 24GHz 毫米波雷达** 的停车防盗哨兵：检测设备附近 2 米内是否有人靠近，触发拍照并推送到手机提醒。

典型场景：车停在小区楼下，车内/车上放有物品，担心被盗。有人靠近车辆 → 自动拍照 → 手机收到微信提醒。

## 功能特性

- **毫米波人体存在检测**：LD2410B（24GHz FMCW），能检测运动与静止人体（呼吸微动），比 PIR 红外传感器可靠得多
- **2 米距离门控**：通过雷达固件配置感应范围，只有目标进入设定距离（2m 内）才触发
- **低功耗哨兵模式**：ESP32 deep sleep 待机，雷达检测到人后通过 GPIO 唤醒，拍照、推送、回到睡眠
- **本地取证存储**：抓拍照片同时存入 SD 卡，不依赖云端，隐私可控
- **手机实时提醒**：企业微信机器人 / Server酱（零成本）或自建服务器（数据完全自托管）
- **误报抑制**：触发延时过滤路人、拍照冷却时间、可选光敏联动（仅夜间警戒）

## 系统架构

```
[LD2410B 毫米波雷达]  →  [ESP32-CAM 主控]  →  [WiFi / 4G Cat.1]  →  [云端/微信推送]  →  [手机提醒]
  感应层：2m 检测          决策层：唤醒拍照       传输层：无网用 4G     提醒层：图片+时间
```

详细说明见 [docs/architecture.md](docs/architecture.md)
