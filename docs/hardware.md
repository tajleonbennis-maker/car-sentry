## 采购建议（避坑）

1. **ESP32-CAM 认准 AI-Thinker 原厂**，别买无牌散货——夜间成像噪点、WiFi 信号弱、5V 供电不稳导致拍照重启，大多出在山寨版
2. 雷达建议买**蓝牙版（BLE 版）**：可直接用手机 APP（HLKRadarTools）配置距离门和灵敏度，省去串口接线麻烦
3. ESP32-CAM 拍照+WiFi 发射时峰值电流 **可达 800mA-1A**，调试用 5V/2A 电源，电脑 USB 口电流不足会反复重启
4. SD 卡建议 Class10、≤32GB、FAT32（容量过大或 U3 高速卡易出兼容问题）

## 供电方案

### 方案 A：车常电 + 低压保护（推荐，简单可靠）

- 从 OBD 或保险盒取常电（ACC 熄火后仍有电）
- **必须加低压保护**：电压低于 ~11.8V 自动断电，防止耗尽电瓶导致打不着火
  - 成品：汽车电瓶电压保护器（约 ¥15-25）
  - 或自焊：电压比较器（如 TLV431）+ P-MOSFET
- 优点：无需考虑续航；缺点：接线有门槛，且依赖车辆常电

### 方案 B：锂电池/充电宝 + 太阳能（免接线）

- 10000mAh 移动电源（需支持小电流输出，防止低负载自动关机）或 18650×2 + TP4056 充电模块
- 功耗估算：雷达常开 79mA + ESP32 睡眠几 mA ≈ **85mA 平均** → 10000mAh 约撑 **5 天**
- 加 5W 太阳能板 + CN3791 太阳能充电模块（约 ¥40-50 总价）：晴天日补 ~20Wh，可基本维持长期运行
- 优点：不动车电路、隐蔽性好；缺点：续航/补电依赖天气与日照

### 方案 C（进阶）：PIR 粗触发降功耗

- 加 ¥3 的 PIR 先做运动检测，检测到运动才给雷达上电 → 待机电流降到 ~1mA 级，10000mAh 可撑数月
- **注意**：普通车窗玻璃对 8-14μm 热辐射不透明，PIR 必须装在车外（如贴窗沿/后视镜），否则隔着玻璃失灵
- 权衡：省电但逻辑复杂化，且 PIR 对缓慢移动的人可能漏报
