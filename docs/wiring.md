# 接线与固件烧录

## 核心接线（LD2410B ↔ ESP32-CAM）

ESP32-CAM 可用 GPIO 有限（大量引脚被摄像头/PSRAM/SD 占用），本方案**运行时只使用雷达的 OUT 引脚**，避免 GPIO 冲突：

| LD2410B | ESP32-CAM | 说明 |
|---|---|---|
| 5V | 5V（共用供电输入） | 雷达与主控同源供电 |
| GND | GND | 共地 |
| **OUT** | **GPIO13** | 有人进入设定距离 → 拉高 → 唤醒 deep sleep 的 ESP32（GPIO13 是 RTC GPIO，支持外部唤醒） |
| TX / RX | 仅开发时接（见下） | 运行时不需要，避免与 SD 卡（GPIO16 占用）冲突 |

> 引脚选择说明：GPIO13 为 ESP32-CAM 未占用的 RTC GPIO，可配置 `EXT1` 外部唤醒。GPIO16 已被 MicroSD 卡 CS 占用，串口雷达常规接法（GPIO16/17）会与 SD 卡冲突，因此设计为「运行时只读 OUT、串口仅用于一次性配置」。

## 雷达距离配置（一次性，掉电保存）

"2 米内才触发"由雷达固件完成，有两种方式：

### 方式一：手机 APP（推荐，需 BLE 版雷达）

1. 下载官方 APP：**HLKRadarTools**（安卓/iOS）
2. 蓝牙连接 LD2410B
3. 设置：**最大距离门 = 3（对应 2.25m）**，起始距离门按需（如 1）
4. 保存配置，掉电不丢失

### 方式二：串口命令（普通版雷达）

用 USB-TTL 模块接雷达串口，发送配置命令（协议见官方《LD2410 串口通信协议》）：

```
FD FC FB FA 0C 00 60 00 03 00 03 00 00 00 03 00 03 00 00 00 00 00 00 00 00 00 04 03 02 01
```

- `0x60` 命令字：设置最大距离门和无人持续时间
- `03 00`（运动）/ `03 00`（静止）：最大距离门 = 3（2.25m）
- 配置掉电保存，重启生效

## 固件烧录（首次）

1. **接线**：CH340G ↔ ESP32-CAM（U0R→TX、U0T→RX、5V→5V、GND→GND），**GPIO0 短接 GND 进入烧录模式**
2. **Arduino IDE 配置**：
   - 开发板管理器 URL：`https://dl.espressif.com/dl/package_esp32_index.json`
   - 开发板：`AI Thinker ESP32-CAM`
   - PSRAM：Enabled；Flash Mode：QIO；Partition：Huge APP
3. 上传代码后**断开 GPIO0 与 GND**，按复位键重启
4. 串口监视器查看日志（115200）

## 硬件调试 checklist

- [ ] 5V/2A 电源供电（电脑 USB 口不够，会重启）
- [ ] 摄像头排线方向正确（金手指朝向板子外侧）
- [ ] 雷达 OUT → GPIO13 接线确认
- [ ] 雷达距离门配置完成（≤2.25m）
- [ ] 触发测试：人走进 2m 范围 → ESP32 被唤醒 → 拍照存 SD

## 开发阶段注意

- 调试时建议先把「拍照推送」注释掉，只做「触发 → 拍照 → 存 SD → 串口日志」，验证链路
- deep sleep 唤醒后要重新初始化摄像头和外设（ESP32 deep sleep 会掉内存）
- 4G 模块建议用 GPIO 控制的 MOSFET 电源开关，平时断电省电
