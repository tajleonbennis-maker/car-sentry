# 系统架构设计

## 四层架构

| 层 | 组件 | 职责 | 关键参数 |
|---|---|---|---|
| 感应层 | HLK-LD2410B 24GHz 毫米波雷达 | 检测 2m 内人体存在（含静止微动） | FMCW，0.75-6m 可配，±60°，5V / ~79mA |
| 决策层 | ESP32-CAM（OV2640） | 唤醒、距离判定、拍照、本地存储 | deep sleep 待机，拍照峰值 ~800mA |
| 传输层 | WiFi（2.4G）或 4G Cat.1 | 上报事件与图片 | 无网环境必须 4G |
| 提醒层 | 企业微信/Server酱/自建服务器 | 推送图片+时间到手机 | 可完全自托管 |

## 为什么选毫米波雷达（而非 PIR）

- PIR 红外热释电只能检测**运动**的人，对静止/缓慢移动的人无效，隔着车玻璃更差
- LD2410B 用 FMCW 调频连续波，能检测**静止人体的呼吸微动**（存在检测），可靠性高
- 支持通过距离门（gate）精确限制感应范围，天然满足"2 米内才报警"
- 支持 GPIO 输出（OUT 引脚），可直接唤醒处于 deep sleep 的 ESP32

## 低功耗状态机

```
[睡眠] ──目标进入2m内──▶ [雷达确认] ──延时1-2s过滤路人──▶ [拍照推送] ──▶ [冷却 30-60s] ──▶ 回到[睡眠]
 雷达常开探测             OUT引脚拉高唤醒ESP32            连拍2-3张存SD         静默防频繁触发
                                                        + 上传+微信提醒
```

关键点：

1. **雷达常开**：LD2410B 约 79mA，是唯一常开器件，必须持续探测
2. **ESP32 deep sleep**：待机电流从 ~80mA 降到 ~1mA 级别，只在触发时唤醒
3. **4G 模块平时断电**：用 MOSFET 控制，拍照上传时才上电（待机省电）
4. **拍照瞬间峰值电流大**（ESP32 + WiFi/4G 发射可达 1A 级），供电必须有足够余量

## 通信决策（本项目最大决策点）

| 场景 | 方案 | 说明 |
|---|---|---|
| 车位有 WiFi 覆盖（一楼/车位在楼边） | WiFi 直连 | 零成本，实现最简单 |
| 车位无 WiFi（最常见） | **4G Cat.1（推荐）** | 合宙 Air780E/Air724UG + 物联网卡，HTTP/MQTT 直推 |
| 手机在场 | BLE（不推荐） | 距离受限，且 iOS 后台限制，不可靠 |

> 结论：小区楼下车位通常收不到家里 WiFi 信号，**默认按 4G Cat.1 设计**，WiFi 作为降级选项保留。

## 误报抑制策略

1. **距离门控**：雷达最大距离门配到 2.25m（gate 3），2m 外的目标不触发
2. **触发延时**：LD2410B 新版固件支持 1-2s 延时触发，路人快速经过不报警，停留才报警
3. **冷却时间**：拍照推送后静默 30-60s，避免连环触发
4. **光敏联动**：雷达带光敏二极管，可配置白天不触发、夜间高灵敏度（防盗重点时段）

## 进阶优化（可选）

- **PIR 粗触发**：加 ¥3 的 PIR 先检测运动，再唤醒雷达做存在确认，待机电流可降到 1mA 级（注意 PIR 需装在车外，普通车窗玻璃对 8-14μm 热辐射不透明）
- **车主识别**：手机 BLE 广播固定 UUID，ESP32 扫描到车主手机则静默（Android 可行；iOS 后台广播受限，有坑）
- **太阳能补电**：5W 太阳能板 + CN3791 充电模块，晴天可抵消 79mA 常开功耗
